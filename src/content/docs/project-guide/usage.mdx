# Usage Guide

คู่มือการใช้งาน Documentation Site - เรียนรู้วิธีเพิ่มและจัดการเอกสาร

## ภาพรวมการทำงาน

Documentation Site นี้ใช้ระบบ **Dynamic Navigation** ที่อิงจากไฟล์ `docs-config.json` ทำให้คุณสามารถเพิ่มหรือลบเอกสารได้ง่ายๆ โดยไม่ต้องแก้ไขโค้ดหลัก

## การเพิ่มเอกสารใหม่

### ขั้นตอนที่ 1: สร้างโฟลเดอร์และไฟล์ MDX

สร้างโฟลเดอร์ใหม่ใน `src/content/docs/`:

```bash
mkdir src/content/docs/my-section
```

สร้างไฟล์ MDX:

```bash
touch src/content/docs/my-section/my-page.mdx
```

### ขั้นตอนที่ 2: เขียน Frontmatter

เปิดไฟล์ที่สร้างและเพิ่ม frontmatter:

```markdown
---
title: "ชื่อเอกสาร"
description: "คำอธิบายสั้นๆ เกี่ยวกับเอกสารนี้"
order: 1
category: "my-section"
---

# ชื่อหัวข้อหลัก

เนื้อหาเอกสารของคุณ...

## หัวข้อย่อย

รายละเอียดเพิ่มเติม
```

**Frontmatter Fields:**
- `title`: ชื่อที่แสดงบนหน้าเอกสาร (required)
- `description`: คำอธิบายสั้นๆ (required)
- `order`: ลำดับการแสดง (optional)
- `category`: หมวดหมู่ของเอกสาร (required)

### ขั้นตอนที่ 3: อัพเดท Navigation Config

แก้ไขไฟล์ `docs-config.json`:

```json
{
  "navigation": [
    {
      "title": "My Section",
      "slug": "my-section",
      "items": [
        {
          "title": "My Page",
          "slug": "my-section/my-page"
        }
      ]
    }
  ]
}
```

### ขั้นตอนที่ 4: ตรวจสอบผลลัพธ์

เปิดเบราว์เซอร์ที่:
```
http://localhost:4321/docs/my-section/my-page
```

เอกสารใหม่จะปรากฏใน Sidebar อัตโนมัติ! ✨

## Best Practices

### การตั้งชื่อไฟล์

- ใช้ lowercase และ kebab-case: `my-awesome-doc.mdx`
- ใช้ชื่อที่สื่อความหมาย
- หลีกเลี่ยงอักขระพิเศษ

### การจัดโครงสร้าง

```
docs/
├── getting-started/
│   ├── introduction.mdx
│   └── installation.mdx
├── guides/
│   ├── basic-usage.mdx
│   └── advanced-usage.mdx
└── api/
    ├── authentication.mdx
    └── endpoints.mdx
```

### การเขียนเนื้อหา

1. **ใช้ Headings อย่างเหมาะสม**
   - H1 (`#`) สำหรับชื่อหลัก (1 ครั้งต่อหน้า)
   - H2 (`##`) สำหรับหัวข้อใหญ่
   - H3 (`###`) สำหรับหัวข้อย่อย

2. **เพิ่ม Table of Contents**
   - TOC จะ generate อัตโนมัติจาก H2 และ H3
   - ใช้ headings ที่ชัดเจนและสั้นกระชับ

3. **Code Examples**
   - ระบุภาษาใน code blocks
   - เพิ่ม comments อธิบายโค้ด
   - ให้ตัวอย่างที่สมบูรณ์

### ลบไฟล์

```bash
rm src/content/docs/section/page.mdx
```

### ลบจาก Navigation

ลบ entry ออกจาก `docs-config.json`:

```json

  "items": [
    // ลบ object นี้ออก
    // {

    //   "slug": "section/old-page"
    // }
  ]
}
```

## Tips & Tricks

### ค้นหาเอกสาร

ใช้ text editor search (VS Code: `Cmd/Ctrl + Shift + F`)

### Preview ระหว่างเขียน

Dev server จะ auto-reload เมื่อบันทึกไฟล์

### ตรวจสอบ Broken Links

```bash
npm run build
```

Build process จะแจ้งเตือนถ้ามี broken links

### Backup Config

สำรอง `docs-config.json` ก่อนแก้ไขครั้งใหญ่:

```bash
cp docs-config.json docs-config.json.backup
```
