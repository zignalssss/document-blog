# แนะนำ Python

Python เป็นภาษาโปรแกรมมิ่งระดับสูงที่เน้นความเรียบง่ายและอ่านง่าย

## ทำไมต้อง Python?

- 🚀 **เรียนรู้ง่าย** - Syntax ที่อ่านเข้าใจง่าย
- 📚 **Library เยอะ** - มี packages มากมายสำหรับทุกงาน
- 🌐 **ใช้งานหลากหลาย** - Web, AI, Data Science, Automation
- 👥 **Community ใหญ่** - มีคนช่วยเหลือเยอะ

## ตัวอย่างโค้ด

```python
# Hello World
print("Hello, Python!")

# ตัวแปร
name = "Python"
version = 3.11

# Function
def greet(name):
    return f"สวัสดี {name}!"

print(greet("World"))
```

## การใช้งาน Python

Python ใช้ได้กับ:
- **Web Development** - Django, Flask
- **Data Science** - Pandas, NumPy, Matplotlib
- **Machine Learning** - TensorFlow, PyTorch, Scikit-learn
- **Automation** - Selenium, BeautifulSoup
- **Game Development** - Pygame
