# แนะนำ Go

Go (Golang) เป็นภาษาโปรแกรมมิ่งที่พัฒนาโดย Google เน้นความเร็วและความเรียบง่าย

## ทำไมต้อง Go?

- ⚡ **รวดเร็ว** - Compile เป็น machine code
- 🔄 **Concurrency** - Built-in support ด้วย goroutines
- 🛠️ **เรียบง่าย** - Syntax ที่กระชับและชัดเจน
- 📦 **Static Binary** - Deploy ง่าย ไม่ต้องติดตั้ง runtime

## ตัวอย่างโค้ด

```go
package main

import "fmt"

func main() {
    // Hello World
    fmt.Println("Hello, Go!")
    
    // ตัวแปร
    name := "Go"
    version := 1.21
    
    // Function
    greeting := greet("World")
    fmt.Println(greeting)
}

func greet(name string) string {
    return fmt.Sprintf("สวัสดี %s!", name)
}
```

## การใช้งาน Go

Go เหมาะกับ:
- **Backend Services** - APIs, Microservices
- **Cloud Infrastructure** - Kubernetes, Docker
- **CLI Tools** - Command-line applications
- **Network Programming** - Servers, Proxies
- **DevOps Tools** - Terraform, Prometheus

## จุดเด่นของ Go

### Goroutines

```go
go func() {
    fmt.Println("Running in goroutine")
}()
```

### Channels

```go
ch := make(chan string)
go func() {
    ch <- "Hello"
}()
msg := <-ch
```

### Error Handling

```go
result, err := divide(10, 0)
if err != nil {
    fmt.Println("Error:", err)
    return
}
```
