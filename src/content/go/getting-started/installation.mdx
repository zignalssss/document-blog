# การติดตั้ง Go

## ดาวน์โหลด Go

ดาวน์โหลดจาก [go.dev/dl](https://go.dev/dl/)

## ติดตั้งบน Windows

1. ดาวน์โหลด `.msi` installer
2. รันไฟล์และติดตั้ง
3. เปิด Command Prompt ใหม่

ตรวจสอบ:
```bash
go version
```

## ติดตั้งบน macOS

### ใช้ Homebrew (แนะนำ)

```bash
brew install go
```

### ใช้ Installer

1. ดาวน์โหลด `.pkg` file
2. เปิดและติดตั้ง

## ติดตั้งบน Linux

### Ubuntu/Debian

```bash
# Download
wget https://go.dev/dl/go1.21.0.linux-amd64.tar.gz

# Extract
sudo tar -C /usr/local -xzf go1.21.0.linux-amd64.tar.gz

# Add to PATH
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc
```

## ตั้งค่า GOPATH

```bash
# สร้าง workspace
mkdir -p ~/go/{bin,src,pkg}

# ตั้งค่า environment
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
```

## สร้างโปรเจคแรก

```bash
# สร้าง directory
mkdir hello
cd hello

# Initialize module
go mod init example.com/hello

# สร้างไฟล์ main.go
cat > main.go << 'EOF'
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
EOF

# รันโปรแกรม
go run main.go

# Build
go build
./hello
```

## ติดตั้ง Packages

```bash
# ติดตั้ง package
go get github.com/gin-gonic/gin

# อัพเดท dependencies
go mod tidy

# ดู dependencies
go list -m all
```

```bash

```
